개인정보처리방침

시행일: 2026년 10월 26일

「느린 그림 동화 업로더」(이하 "도구")는 YouTube 채널 「느리고 아름다운 그림 동화」 운영자가 자기 채널을 관리하는 데에만 쓰는 개인용 프로그램입니다.

1. 사용하는 정보

도구는 운영자가 Google 로그인으로 허락한 범위(YouTube 계정 관리) 안에서 운영자 본인 채널의 영상, 재생목록, 썸네일, 채널 통계에만 접근합니다.

2. 사용 목적

운영자가 만든 영상을 올리고, 공개 일정을 예약하고, 제목·설명·썸네일·재생목록을 정리하고, 채널 통계를 확인하는 데에만 씁니다.

3. 저장과 공유

로그인 정보(인증 토큰)는 운영자의 컴퓨터에만 저장됩니다. 도구는 어떤 정보도 별도 서버에 모으지 않으며, 제3자에게 판매하거나 제공하지 않습니다. 시청자의 개인정보는 다루지 않습니다.

4. Google API 사용 정책

Google API로 받은 정보의 사용과 전송은 Google API Services User Data Policy의 제한 사용 요건을 따릅니다.

5. 접근 철회

Google 계정의 타사 앱 및 서비스에서 언제든지 도구의 접근 권한을 철회할 수 있습니다.

6. 문의
